# زندگی من (My Life) 🏠🌸

اپلیکیشن جامع خانواده برای رشد، یادگیری، خاطره‌سازی و برنامه‌ریزی آینده — طراحی شده با عشق برای خانواده‌های ایرانی، با استانداردهای جهانی و آینده‌نگر.

## ✨ ویژگی‌های اصلی

### 👨‍👩‍👧 خانه ما
- **شخصیت‌های سه‌بعدی پیکساری**: یونیکورن، ربات، اژدها، دوقلوها
- **گل زندگی شکوفا**: با هر Erfolg و خاطره، گلبرگ جدیدی باز می‌شود
- **تقویم خوشبختی**: ثبت لحظات شادی با ایموجی و عکس
- **دفتر خاطرات چندحسی**: متن، عکس، استیکر، قفل شخصی
- **دفتر رنگ‌آمیزی**: تبدیل عکس خانواده به نقاشی کارتونی
- **شگفتی‌های شب**: حیوانات، ستاره‌ها، فرهنگ ایران کهن

### 🌿 دنیای من به سبک من (سلامت، روان، توانبخشی) **جدید!**
- **پروفایل‌های نیازهای ویژه**: اوتیسم، ADHD، دیسلکسی، معلولیت فیزیکی، نابینا، ناشنوا، اختلال گفتاری، اضطراب، افسردگی
- **تنظیمات حسی شخصی**: کم‌تحریک، کنتراست بالا، فونت دیسلکسی، کاهش حرکت، ویبره، کنترل صوتی/سوئیچ
- **تمرینات درمانی ۸ دسته**: تنفس، ذهن‌آگاهی، شناختی، حرکتی، گفتاری، تنظیم احساسات، مهارت اجتماعی، یکپارچه‌سازی حسی
- **چک‌ان روزانه احساسات**: ثبت حال، انرژی، خواب، استرس، ردیابی روند هفتگی
- **اهداف درمانی شخصی**: پیشرفت بصری، تمرینات پیشنهادی بر اساس پروفایل
- **زیرنویس و توصیف صوتی کامل** برای تمام محتوای صوتی/تصویری
- **زبان اشاره مجازی**: آواتار سه‌بعدی (یونس، اژدها، ربات، نورانی) برای ترجمه لحظه‌ای
- **پشتیبانی فونت دیسلکسی، فونت بزرگ، فاصله خطوط/حروف قابل تنظیم**

### 📚 یادگیری و رشد
- **زبان تا آیلتس ۱۰**: ۳ روش منحصر به فرد + یادگیری با مامان/بابا
  - ⚔️ گرامر سامورایی (دقیق، منظم)
  - 🗽 ماجراجویی نیویورکی (زینده، واقعی)
  - 🧪 آزمایشگاه اروپایی (علمی، ساختاری)
  - 💕 یاد بگیر با مامان
  - 🌟 یاد بگیر با بابا
- **بازی ریاضی**: از شمارش تا جبر، کاملاً بازی‌محور
- **موسیقی و زندگی**: نت‌خوانی، ریتم، ساز، آهنگ‌سازی، موسیقی ایرانی

### 🚀 مسیر رشد و آینده
- **هوش مصنوعی**: از ChatGPT تا ML Engineering (۷ مرحله)
- **مهاجرت هوشمند**: تحلیل ۶ کشور برتر برای خانواده
- **برنامه‌ریزی روزانه**: XP، Streak، سطح‌بندی مثل Duolingo
- **شگفتی‌های هفتگی**: فرهنگ ایران، مفاخر ایرانی، نجوم کهن

### ⏳ کپسول زمان و دنیای رویا **جدید!**
- **کپسول زمان**: قفل بر اساس سن (۱۸ سالگی)، تاریخ، رویداد (عروسی، مهاجرت)، یا دستی
- **قالب‌های آماده**: تولد ۱۸ سالگی، عروسی، مهاجرت، سفارشی
- **دنیای رویا**: ثبت رویا، نمادها، تفسیر AI (جنگی، فرویدی، مدرن)
- **راهنمای نمادها**: ۱۵+ نماد رایج با معانی
- **اشتراک‌گذاری رویا** با اعضای خانواده

### 🌿 زندگی روزمره
- **دنیای خوشمزه مامان**: غذاهای ایرانی، رژیمی، فست‌فود، فینگر، دسر
- **اقتصاد خانواده**: بودجه‌بندی، آموزش مالی کودک
- **سرزمین آرزوها**: هدف‌گذاری بصری با درخت رشد
- **دنیای حیوانات خانگی**: مراقبت، تغذیه، واقعیت افزوده

### 🔒 امنیت و دسترسی‌پذیری
- **ورود بیومتریک اختیاری**: قفل برنامه با اثر انگشت / تشخیص چهره (Face ID) از طریق تنظیمات پروفایل
- **ذخیره‌سازی محلی و آفلاین**: داده‌ها در دستگاه نگهداری می‌شوند؛ همگام‌سازی ابری در نسخه‌های آینده
- **پشتیبان‌گیری و بازیابی**: صدور/وارد کردن فایل پشتیبان کامل JSON از تنظیمات
- **همگام‌سازی بین دستگاه‌ها (محلی/بسته‌ای)**: ساخت و اشتراک‌گذاری/وارد کردن بسته همگام‌سازی (JSON) از طریق فایل/اشتراک‌گذاری؛ بررسی وضعیت اتصال/تغییرات و ثبت زمان آخرین همگام‌سازی (سینک ابری کامل نیازمند سرویس ابری است)
- **خروجی پرینت سه‌بعدی (STL/OBJ/JSON)**: تولید مش واقعی relief از قلم‌موهای رنگ‌آمیزی (OBJ/STL) به‌همراه داده‌های JSON
- **دسترسی‌پذیری**: تنظیمات کم‌تحریک، کنتراست، فونت/اندازه متن، زیرنویس و گزینه‌های مرتبط در بخش‌های اپ
- **پیکربندی امنیتی**: گزینه‌های رمزنگاری/حریم خصوصی در ساختار داده و تنظیمات (تکمیل تدریجی)

## 🚀 شروع سریع

### پیش‌نیازها
```bash
Node.js 18+
npm یا yarn
Expo CLI: npm install -g expo-cli
EAS CLI: npm install -g eas-cli
```

### نصب و اجرا
```bash
# کلون پروژه
git clone <repository-url>
cd my-life-app

# نصب وابستگی‌ها
npm install

# بررسی تایپ (TypeScript)
npm run typecheck
# یا:
npm run check

# اجرا در حالت توسعه
npm start

# اجرا روی اندروید
npm run android

# اجرا روی iOS
npm run ios

# اجرا روی وب
npm run web
# یا روی پورت مشخص:
npm run web:8081
```

### ساخت APK
```bash
# نصب EAS CLI
npm install -g eas-cli

# لاگین در اکسپو
eas login

# کانفیگ پروژه
eas build:configure

# ساخت پیش‌نمایش (APK داخلی)
eas build --platform android --profile preview

# ساخت تولید (AAB برای پلی‌استور)
eas build --platform android --profile production
```

## 📄 مستندات توسعه

### معماری
- **Modular Architecture**: هر فیچر ماژول مستقل
- **Core Engine**: مدیریت_state، تم، ناوبری، صوت
- **Plugin System**: افزودن فیچرهای جدید بدون تغییر هسته
- **Offline-First**: IndexedDB/AsyncStorage + Cloud Sync

### دیتابیس (AsyncStorage Schema)
```typescript
interface AppData {
  familyMembers: FamilyMember[];
  memories: Memory[];
  calendarEvents: CalendarEvent[];
  lifeFlower: LifeFlowerState;
  dailyPlan: DailyPlan;
  xpState: XPState;
  coloringPages: ColoringPage[];
  settings: AppSettings;
  nightWonders: NightWonder[];
  // + wellness, time capsules, dreams, accessibility, backup/security config, etc.
}
```

### امنیت
- ذخیره‌سازی محلی داده‌ها با `AsyncStorage` و پشتیبان‌گیری/بازیابی JSON
- قفل ورود اختیاری با بیومتریک دستگاه (`expo-local-authentication`: اثر انگشت / Face ID) با fallback رمز دستگاه
- پیکربندی امنیتی/حریم خصوصی (2FA، حالت خصوصی، رمزنگاری پیشرفته) در ساختار اپ — تکمیل تدریجی
- توصیه: قبل از انتشار نهایی، `expo.extra.eas.projectId` و `owner` در `app.json` را با مقادیر واقعی تنظیم کنید
